# 双服务回归记录

日期：2026-09-13。环境：macOS arm64。开发环境 Node 25.8.1；另从干净源码使用官方 Node 24.13.0 完成安装与回归。测试使用隔离数据库和端口，没有迁移或重启原 4360 验收实例，没有调用付费模型或地图 API。

## 已验证范围

- 全量功能回归：旅行层级、笔记、地图数据、关键卡片、权限、共享、版本冲突、提议采用/撤销、媒体、轨迹和备份迁移。
- 双进程专项：独立 Worker 完成研究，原子采用与幂等重试，整体撤销；SIGKILL Worker 后研究中断，功能服务仍可手动创建旅行，不自动重新调用模型。
- 内部协议：错误凭据、浏览器 Cookie、版本不符、重复操作、冲突操作、取消后的回调及过期完成提交均有校验。
- 浏览器和图片：通过 HTTP 返回正文和二进制截图；图片转换、缩略图生成在 Worker 执行，功能服务验证并保存，消费后删除中转附件。
- 卡片模型提取独立于 Agent；不完整和过大响应被拒绝。
- v7→v8 业务表保持不变，已有 v1—v6 迁移样本同时回归；重启后旧执行任务不被重放。
- 真实固定版本 Harness 的启动、服务注册和健康检查；实际 Cordis/Session v2 的远程日志落盘、刷新、重新打开、写入者约束和非法事件拒绝。
- 生产构建后功能服务实际 HTTP 启动、首次安装凭据、幂等重试、停止与重启持久化。

以上自动化通过不代表实时模型回答质量或全部浏览器网站可用性。浏览器正文与截图的回归使用受控后端；本轮未重新请求付费研究。
